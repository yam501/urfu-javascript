# ЛР №7 — Обходы дерева без рекурсии

BFS и три порядка DFS (preorder / inorder / postorder) на абстрактной структуре «родитель — потомки». Рекурсия не используется: вместо стека вызовов — явная очередь и явные стеки.

Разбор и результаты — в [REPORT.md](REPORT.md).

```bash
npm install
npm run typecheck # tsc --noEmit (strict)
npm run bench     # обходы на примерах + сверка с рекурсивным эталоном + 1 000 000 узлов
```

| Файл | Что внутри |
|---|---|
| `src/tree.ts` | `TreeLike` (значение + упорядоченный список потомков), `TreeNode`, литерал `node()`, цепочка `chain()`, случайное дерево `randomTree()` |
| `src/traversals.ts` | `bfs` (очередь), `dfsPreorder` (стек), `dfsPostorder` (два стека), `dfsInorder` (стек кадров) — всё без рекурсии |
| `src/bench.ts` | обходы на демо-дереве, inorder на бинарном дереве поиска, сверка с рекурсивным эталоном на 300 случайных деревьях, предел стека вызовов, времена на 1 000 000 узлов |
